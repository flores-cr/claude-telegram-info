# Privacy policy for claude-telegram

Last updated: 2026-11-21

claude-telegram is a personal tool used by one person, its owner. It is not offered to anyone else.

**Data accessed.** With the owner's consent, the app reads and edits the owner's Google Tasks (the `tasks` scope).

**Storage.** The OAuth token is stored only on the owner's own computer. Task data is read when the owner asks and is not kept in a database.

**Sharing.** The app does not sell, share or transfer Google user data to anyone. Task content is processed only to answer the owner's own requests in a private chat.

**Retention and deletion.** The owner can revoke access at any time at https://myaccount.google.com/permissions, and delete the local token file.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
